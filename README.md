# Selawi Cockpit

A native Android (Kotlin + Jetpack Compose) cockpit app for the BYD Seal 05 DM-i head unit:
a full-screen, customizable dashboard with maps, media, app shortcuts and an AI voice assistant.
It is a normal app the driver opens. It does not replace or modify BYD's own software.

## Current stage: Phase 0 (device check)

`probe/` is a small test app that reports what the head unit supports before the cockpit is built.
See [docs/PHASE0_REPORT.md](docs/PHASE0_REPORT.md) for research, decisions, the on-car test
checklist and results.
